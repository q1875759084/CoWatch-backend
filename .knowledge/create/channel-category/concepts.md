## 业务范围

### 模块包含的功能

渠道类目模块负责商品在多个销售渠道上的分类管理。**核心职责**包括：

| 功能 | 说明 |
|------|------|
| **渠道类目** | 商品创建/编辑时选择和映射渠道类目 |
| **渠道类目属性** | 管理每个渠道类目下的动态属性（品牌、产地等） |
| **渠道特殊图** | 特定渠道/类目的展示图片管理（如渠道商品资质等） |
